# Conimus-Erweiterungen

Skills und Konnektoren für **Conimus**, eine selbst gebaute KI.

Erweiterungen sind reine JSON-Dateien ohne Programmcode. Conimus liest sie nur.

- `katalog.json` – Liste aller Erweiterungen in diesem Lager
- `skills/` – Wissen und feste Antworten (Spickzettel, Antworten)
- `konnektoren/` – Datenquellen im Internet (nur lesen, eine feste Adresse pro Konnektor)

**Einbinden:** In Conimus unter Einstellungen → Skills oder Konnektoren → „holen“
das Lager `cengiz54091-bot/conimus-erweiterungen` auswählen. Kein GitHub-Konto nötig.
